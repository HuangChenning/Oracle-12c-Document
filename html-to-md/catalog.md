# Oracle Database 12c Release 2 文档目录

路径都相对于本文件所在的 `html-to-md` 目录。检索时先选定一本书，再打开该书的 `contents.md`。

## 概念与升级

- `concepts/contents.md`：Database Concepts（E85769-04）。数据库体系结构、事务、存储、进程和数据字典。
- `new-features-guide/contents.md`：Oracle Database New Features Guide（E85871-02）。12.2 的新特性。

## 管理、参数与排错

- `administrators-guide/contents.md`：Database Administrator's Guide（E85760-09）。建库、启动关闭、表空间、用户、调度和诊断。
- `performance-tuning-guide/contents.md`：Database Performance Tuning Guide（E85600-04）。实例调优、等待事件和统计信息。
- `sql-tuning-guide/contents.md`：SQL Tuning Guide（E85762-06）。SQL 执行计划、优化器和调优方法。
- `reference/contents.md`：Database Reference（E85634-25）。初始化参数、静态数据字典视图和动态性能视图。在线文档 E85634-25，本地 PDF 为 E85634-24。

## 高可用

- `data-guard-concepts-and-administration/contents.md`：Data Guard Concepts and Administration（E85767-01）。Data Guard 物理/逻辑备库的概念和管理。
- `data-guard-broker/contents.md`：Data Guard Broker（E85768-01）。用 Broker 配置和切换 Data Guard。

## 备份与恢复

- `backup-and-recovery-users-guide/contents.md`：Database Backup and Recovery User's Guide（E85627-04）。RMAN 备份、恢复和闪回的用法。
- `backup-and-recovery-reference/contents.md`：Database Backup and Recovery Reference（E85640-04）。RMAN 命令和恢复目录视图。

## 安全

- `security-guide/contents.md`：Database Security Guide（E85682-14）。用户、权限、审计和数据加密等安全配置。

## SQL

- `sql-language-reference/contents.md`：SQL Language Reference（E83703-08）。SQL 语句、函数、数据类型和语法图。

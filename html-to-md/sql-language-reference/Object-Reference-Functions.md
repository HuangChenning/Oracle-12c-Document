Object reference functions manipulate `REF` values, which are references to objects of specified object types. The object reference functions are:

- [DEREF](DEREF.md)
- [MAKE\_REF](MAKE_REF.md)
- [REF](REF.md)
- [REFTOHEX](REFTOHEX.md)
- [VALUE](VALUE.md)

[Oracle Database Object-Relational Developer's Guide](https://docs.oracle.com/pls/topic/lookup?ctx=en/database/oracle/oracle-database/12.2/sqlrf&id=ADOBJ00805) for more information about `REF` data types

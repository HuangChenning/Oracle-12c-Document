This appendix describes mechanisms that lock data either automatically or as specified by the user during SQL statements. For a general discussion of locking mechanisms in the context of data concurrency and consistency, see [Oracle Database Concepts](https://docs.oracle.com/pls/topic/lookup?ctx=en/database/oracle/oracle-database/12.2/sqlrf&id=CNCPT1313).

This appendix contains the following sections:

- [Automatic Locks in DML Operations](Automatic-Locks-in-DML-Operations.md)
- [Automatic Locks in DDL Operations](Automatic-Locks-in-DDL-Operations.md)
- [Manual Data Locking](Manual-Data-Locking.md)

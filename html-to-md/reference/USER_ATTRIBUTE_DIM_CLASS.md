`USER_ATTRIBUTE_DIM_CLASS` describes the classifications of the attribute dimensions owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_ATTRIBUTE_DIM_CLASS`.

Note:

This view is available starting with Oracle Database 12c Release 2 (12.2.0.1).

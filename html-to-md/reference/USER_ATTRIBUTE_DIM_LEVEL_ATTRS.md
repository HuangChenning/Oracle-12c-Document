`USER_ATTRIBUTE_DIM_LEVEL_ATTRS` describes the attributes of the levels of the attribute dimensions owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_ATTRIBUTE_DIM_LEVEL_ATTRS`.

Note:

This view is available starting with Oracle Database 12c Release 2 (12.2.0.1).

`DBA_HIVE_PART_KEY_COLUMNS` provides information about all Hive table partition columns in the database. Its columns are the same as those in `ALL_HIVE_PART_KEY_COLUMNS`.

Note:

This view is available starting with Oracle Database 12c Release 2 (12.2.0.1).

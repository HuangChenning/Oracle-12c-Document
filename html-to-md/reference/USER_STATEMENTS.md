`USER_STATEMENTS` SQL statements in stored PL/SQL objects accessible to the user. Its columns (except for `OWNER`) are the same as those in `ALL_STATEMENTS`.

Note:

This view is available starting with Oracle Database 12c Release 2 (12.2.0.1).

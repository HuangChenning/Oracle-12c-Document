The AWR\_PDB views show the local Automatic Workload Repository (AWR) data present on a CDB root or a PDB from where the AWR\_PDB views are accessed.

The AWR\_PDB views on a CDB root show the AWR data stored on the CDB root.

The AWR\_PDB views on a PDB show the AWR data stored on that PDB.

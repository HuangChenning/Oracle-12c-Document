`USER_MINING_MODEL_PARTITIONS` describes the user's own model partitions. Its columns (except `OWNER`) are same as those in `ALL_MINING_MODEL_PARTITIONS`.

Note:

The `USER_MINING_MODEL_PARTITIONS` view is available in Oracle Database 12c Release 2 and later.

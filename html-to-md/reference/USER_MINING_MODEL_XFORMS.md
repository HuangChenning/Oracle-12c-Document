`USER_MINING_MODEL_XFORMS` describes the user-specified transformations embedded with the user's own models. Its columns (except `OWNER`) are same as those in `ALL_MINING_MODEL_XFORMS`.

Note:

The `USER_MINING_MODEL_XFORMS` view is available in Oracle Database 12c Release 2 and later.

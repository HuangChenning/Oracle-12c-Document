`DBA_EXPRESSION_STATISTICS` provides expression usage tracking statistics for all the tables in the database. Its columns are the same as those in `ALL_EXPRESSION_STATISTICS`.

Note:

This view is available starting with Oracle Database 12c Release 2 (12.2.0.1).

`DICTIONARY` contains descriptions of data dictionary tables and views.

| Column | Datatype | NULL | Description |
| --- | --- | --- | --- |
| `TABLE_NAME` | `VARCHAR2(128)` |  | Name of the object |
| `COMMENTS` | `VARCHAR2(4000)` |  | Text comment on the object |

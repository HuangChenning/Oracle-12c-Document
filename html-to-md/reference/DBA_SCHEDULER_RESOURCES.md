`DBA_SCHEDULER_RESOURCES` displays all scheduler resource objects in the database. Its columns are the same as those in `ALL_SCHEDULER_RESOURCES`.

Note:

This view is available starting with Oracle Database 12c Release 2 (12.2.0.1).

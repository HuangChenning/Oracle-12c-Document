`USER_HIER_LEVELS` describes the levels of the hierarchies owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_HIER_LEVELS`.

Note:

This view is available starting with Oracle Database 12c Release 2 (12.2.0.1).

`DBA_ATTRIBUTE_DIM_KEYS` describes the keys of all attribute dimensions in the database. Its columns are the same as those in `ALL_ATTRIBUTE_DIM_KEYS`.

Note:

This view is available starting with Oracle Database 12c Release 2 (12.2.0.1)

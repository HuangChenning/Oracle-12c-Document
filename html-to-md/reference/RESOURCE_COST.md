`RESOURCE_COST` lists the cost for each resource.

| Column | Datatype | NULL | Description |
| --- | --- | --- | --- |
| `RESOURCE_NAME` | `VARCHAR2(32)` | `NOT NULL` | Name of the resource |
| `UNIT_COST` | `NUMBER` | `NOT NULL` | Cost of the resource |

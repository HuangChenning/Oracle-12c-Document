`DBA_MINING_MODEL_XFORMS` describes the user-specified transformations embedded in all models accessible in the system. Its columns are the same as those in `ALL_MINING_MODEL_XFORMS`.

Note:

This view is available starting with Oracle Database 12c Release 2 (12.2.0.1).

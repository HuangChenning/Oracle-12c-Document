`USER_HOST_ACES` describes the status of access control entries for the current user to access network hosts through PL/SQL network utility packages.

Its columns (except for `ACE_ORDER`, `START_DATE`, `END_DATE`, `GRANT_TYPE`, `INVERTED_PRINCIPAL`, `PRINCIPAL`, `PRINCIPAL_TYPE,` and `STATUS`) are the same as those in `DBA_HOST_ACES`.

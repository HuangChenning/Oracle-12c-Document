`USER_HIVE_TAB_PARTITIONS` provides information about all Hive table partitions owned by the current user in the database. Its columns are the same as those in `ALL_HIVE_TAB_PARTITIONS`.

Note:

This view is available starting with Oracle Database 12c Release 2 (12.2.0.1).

`USER_HIVE_COLUMNS` describes all Hive columns owned by the current user in a Hive metastore. Its columns are the same as those in `ALL_HIVE_COLUMNS`.

Note:

This view is available starting with Oracle Database 12c Release 2 (12.2.0.1).

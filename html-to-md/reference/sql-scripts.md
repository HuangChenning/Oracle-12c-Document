This appendix describes SQL scripts that are required for optimal operation of the Oracle Database.

The SQL scripts are described in the following sections:

- [Creating the Data Dictionary](creating-the-data-dictionary.md)
- [Creating Additional Data Dictionary Structures](creating-additional-data-dictionary-structures.md)
- [The "NO" Scripts](the-no-scripts.md)
- [Upgrade Scripts](upgrade-scripts.md)
- [Java Scripts](java-scripts.md)

Note:

Comments within the SQL scripts themselves contain more detailed information and examples.

Note:

To run scripts in a pluggable database (PDB), connect to the PDB before running the script. For more information about running scripts in a multitenant container database (CDB), see [Oracle Database Administrator’s Guide](https://docs.oracle.com/pls/topic/lookup?ctx=en/database/oracle/oracle-database/12.2/refrn&id=ADMIN14072).
